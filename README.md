# IRON ASCENT

Learn fitness by playing it. A Flutter low-poly 3D fitness RPG: **Build Your First Chest Day**.

The six documents in `docs/` are the implementation contract. Gameplay stays in pure Dart; frame state stays in the game runtime.

## MVP progress

- [x] Inspect specifications and publish original source

- [ ] Structured content, domain rules and tests
- [ ] Persistent save / Continue / reset
- [ ] Generated assets, 3D gym, movement and collision
- [ ] World interactions, quest, Codex and session builder
- [ ] Training, condition, recovery and permanent rewards
- [ ] Product screens, accessibility and safe RevenueCat adapter
