The idea

Not a tracker. A world.

  • Most fitness apps list exercises. IRON ASCENT makes you walk to the machine, inspect it, and understand its role.
  • Training has consequences: fatigue rises, hydration drops, recovery matters.
  • Knowledge is progression: discoveries fill the Iron Codex; the quest unlocks Chest Programming I.
  • Principle: the world teaches, the UI clarifies, the player acts.

Under the hood

Built to grow beyond chest day

  • Flutter + flutter_scene 3D runtime; frame state never touches app state.
  • Pure Dart domain: rules, quest engine, events — 67 automated tests.
  • Data-driven content: exercises, quest, district, NPC, knowledge as JSON.
  • Generated original assets: reproducible GLB kit + synthesized audio.
  • Deployed on Vercel, embeddable in any host (?embed=1 + message bridge for FlutterFlow WebViews).
